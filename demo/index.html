How it works:

  • Uses DataView for proper binary data handling
  • Skips OpusTags from first file (optional metadata)
  • Skips both headers from subsequent files
  • Renumbers page sequences continuously
  • Adjusts granule positions cumulatively
  • Clears all EOS flags for append-only compatibility
  • Uses serial number from first file for deterministic output
  • Recalculates CRC32 checksums
